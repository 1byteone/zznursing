# 设备管理功能 - 项目复盘笔记

> 本笔记用于Java后端面试项目经历复盘，通过代码思维链快速熟悉和回顾设备管理功能的业务实现。

## 一、功能概述

### 1.1 业务背景
在养老院智能管理系统中，需要对接华为云IoT平台，实现物联网设备的统一管理。包括产品同步、设备注册、设备绑定位置、设备数据接收等功能，为后续的智能监测、健康预警等业务提供基础支撑。

### 1.2 核心功能
| 功能模块 | 描述 |
|---------|------|
| 产品同步 | 从华为云IoT平台同步产品列表到Redis缓存 |
| 设备注册 | 在华为云IoT平台注册设备，并在本地数据库维护设备信息 |
| 设备绑定 | 将设备与物理位置（楼层/房间/床位）或老人进行绑定 |
| 设备管理 | 设备查询、修改、删除等CRUD操作 |
| 数据接收 | 通过AMQP协议接收设备上报的数据 |

### 1.3 技术栈
| 技术 | 用途 |
|------|------|
| 华为云IoTDA SDK | 设备管理、产品管理等API调用 |
| Redis | 产品列表缓存、设备数据缓存 |
| AMQP (Qpid JMS) | 设备数据实时接收 |
| MyBatis-Plus | 数据持久层 |
| Spring Boot | 后端框架 |
| Hutool | JSON处理、工具类 |

```java
    private HuaWeiIotConfigProperties huaWeiIotConfigProperties;
```

### 3.2 产品同步到Redis

**文件路径**：`zzyl-nursing-platform/src/main/java/com/zzyl/nursing/service/impl/DeviceServiceImpl.java`

```java
/**
 * 同步产品列表
 */
@Override
public void syncProductList() {
    // 1. 构建请求参数
    ListProductsRequest listProductsRequest = new ListProductsRequest();
    listProductsRequest.setLimit(50);  // 设置查询条数

    // 2. 调用华为云API
    ListProductsResponse listProductsResponse = iotDAClient.listProducts(listProductsRequest);

    // 3. 校验响应状态
    if (listProductsResponse.getHttpStatusCode() != 200) {
        throw new BaseException("物联网接口 - 查询产品，同步失败");
    }

    // 4. 存储到Redis
    redisTemplate.opsForValue().set(
        CacheConstants.IOT_ALL_PRODUCT_LIST,
        JSONUtil.toJsonStr(listProductsResponse.getProducts())
    );
}
```

**面试要点**：
- **为什么用Redis缓存产品列表？**
  - 产品列表变化频率低，避免每次都调用华为云API
  - 减少网络开销，提高响应速度
  - 华为云API有调用频率限制，缓存可降低调用次数

- **缓存策略**：
  - 使用String类型存储JSON数组
  - 手动触发同步，不设置过期时间
  - 产品变更时重新同步即可

### 3.4 设备注册（核心业务）

```java
@Override
public void registerDevice(DeviceDto dto) {
    // ========== 1. 参数校验 ==========

    // 1.1 判断设备名称是否存在
    Long count = count(Wrappers.<Device>lambdaQuery()
        .eq(Device::getDeviceName, dto.getDeviceName()));
    if (count > 0) {
        throw new BaseException("设备名称已存在，请重新输入");
    }

    // 1.2 判断设备标识是否存在
    count = count(Wrappers.<Device>lambdaQuery()
        .eq(Device::getNodeId, dto.getNodeId()));
    if (count > 0) {
        throw new BaseException("设备标识码已存在，请重新输入");
    }

    // 1.3 判断同一位置是否绑定了相同的产品
    count = count(Wrappers.<Device>lambdaQuery()
        .eq(Device::getProductKey, dto.getProductKey())
        .eq(Device::getBindingLocation, dto.getBindingLocation())
        .eq(Device::getLocationType, dto.getLocationType())
        .eq(dto.getPhysicalLocationType() != null,
            Device::getPhysicalLocationType,
            dto.getPhysicalLocationType()));
    if (count > 0) {
        throw new BaseException("该老人/位置已绑定该产品，请重新选择");
    }

    // ========== 2. 调用华为云API注册设备 ==========

    AddDeviceRequest request = new AddDeviceRequest();
    AddDevice body = new AddDevice();
    body.withProductId(dto.getProductKey());
    body.withDeviceName(dto.getDeviceName());
    body.withNodeId(dto.getNodeId());

    // 设置设备密钥
    AuthInfo authInfo = new AuthInfo();
    String secret = UUID.randomUUID().toString().replace("-", "");
    authInfo.withSecret(secret);
    body.withAuthInfo(authInfo);
    request.withBody(body);

    AddDeviceResponse response;
    try {
        response = iotDAClient.addDevice(request);
    } catch (Exception e) {
        throw new BaseException("物联网接口 - 注册设备，同步失败");
    }

    // ========== 3. 保存到本地数据库 ==========

    Device device = BeanUtil.toBean(dto, Device.class);
    device.setSecret(secret);
    device.setIotId(response.getDeviceId());
    save(device);
}
```

**面试要点**：

1. **三重校验机制**：
   - 设备名称唯一性校验
   - 设备标识(nodeId)唯一性校验
   - 位置+产品组合唯一性校验（同一位置不能绑定同类型设备）

2. **分布式事务问题**：
   - 先调用华为云API，再保存本地数据库
   - 如果本地保存失败，华为云上已有设备（需考虑补偿机制）
   - 改进方案：使用消息队列实现最终一致性

3. **密钥生成**：
   - 使用UUID生成随机密钥
   - 去除横线，保证格式统一

### 3.5 查询设备详情

```java
@Override
public DeviceDetailVo queryDeviceDetail(String iotId) {
    // 1. 查询本地设备数据
    Device device = getOne(Wrappers.<Device>lambdaQuery()
        .eq(Device::getIotId, iotId));
    if (ObjectUtil.isEmpty(device)) {
        return null;
    }

    // 2. 调用华为云接口查询设备详情
    ShowDeviceRequest request = new ShowDeviceRequest();
    request.setDeviceId(iotId);
    ShowDeviceResponse response;
    try {
        response = iotDAClient.showDevice(request);
    } catch (Exception e) {
        throw new BaseException("物联网接口 - 查询设备详情，同步失败");
    }

    // 3. 组装返回数据
    DeviceDetailVo vo = BeanUtil.toBean(device, DeviceDetailVo.class);
    vo.setDeviceStatus(response.getStatus());

    // 4. 日期时区转换（UTC → 上海时区）
    String activeTimeStr = response.getActiveTime();
    if (StringUtils.isNotEmpty(activeTimeStr)) {
        LocalDateTime activeTime = LocalDateTimeUtil.parse(
            activeTimeStr, DatePattern.UTC_MS_PATTERN);
        vo.setActiveTime(DateTimeZoneConverter.utcToShanghai(activeTime));
    }

    return vo;
}
```

**面试要点**：
- **数据来源**：本地数据库 + 华为云API组合
- **时区转换**：华为云返回UTC时间，需转换为本地时间
- **状态同步**：设备状态从华为云实时获取

### 3.6 查询设备上报数据（设备影子）

```java
@Override
public AjaxResult queryServiceProperties(String iotId) {
    // 1. 调用华为云API查询设备影子
    ShowDeviceShadowRequest request = new ShowDeviceShadowRequest();
    request.setDeviceId(iotId);
    ShowDeviceShadowResponse response = iotDAClient.showDeviceShadow(request);

    if (response.getHttpStatusCode() != 200) {
        throw new BaseException("物联网接口 - 查询设备影子，调用失败");
    }

    // 2. 获取影子数据
    List<DeviceShadowData> shadow = response.getShadow();
    if (CollUtil.isEmpty(shadow)) {
        return AjaxResult.success(Collections.emptyList());
    }

    // 3. 解析上报数据
    DeviceShadowProperties reported = shadow.get(0).getReported();
    JSONObject jsonObject = JSONUtil.parseObj(reported.getProperties());

    // 4. 处理时间
    String eventTimeStr = reported.getEventTime();
    LocalDateTime eventTimeLocalDateTime = LocalDateTimeUtil.parse(
        eventTimeStr, "yyyyMMdd'T'HHmmss'Z'");
    LocalDateTime eventTime = DateTimeZoneConverter.utcToShanghai(eventTimeLocalDateTime);

    // 5. 封装返回数据
    List<Map<String, Object>> list = new ArrayList<>();
    jsonObject.forEach((k, v) -> {
        Map<String, Object> map = new HashMap<>();
        map.put("functionId", k);      // 属性标识
        map.put("value", v);           // 属性值
        map.put("eventTime", eventTime); // 上报时间
        list.add(map);
    });

    return AjaxResult.success(list);
}
```

**面试要点**：
- **设备影子**：华为云IoT平台的概念，存储设备最新上报的数据
- **数据结构**：`shadow[0].reported.properties` 包含所有属性
- **时间格式**：华为云使用`yyyyMMdd'T'HHmmss'Z'`格式的UTC时间

```java
@Override
public void customUpdateDevice(DeviceDto dto) {
    // 1. 先修改IoTDA平台上的设备名称
    UpdateDeviceRequest request = new UpdateDeviceRequest();
    request.withDeviceId(dto.getIotId());
    UpdateDevice body = new UpdateDevice();
    body.withDescription(dto.getDeviceDescription());
    body.withDeviceName(dto.getDeviceName());
    request.withBody(body);

    try {
        UpdateDeviceResponse response = iotDAClient.updateDevice(request);
    } catch (Exception e) {
        throw new BaseException("物联网接口 - 修改设备信息，同步失败");
    }

    // 2. 校验位置+产品组合唯一性（排除当前设备）
    Long count = count(Wrappers.<Device>lambdaQuery()
        .eq(Device::getProductKey, dto.getProductKey())
        .eq(Device::getBindingLocation, dto.getBindingLocation())
        .eq(Device::getLocationType, dto.getLocationType())
        .ne(Device::getIotId, dto.getIotId())  // 排除当前设备
        .eq(dto.getPhysicalLocationType() != null,
            Device::getPhysicalLocationType,
            dto.getPhysicalLocationType()));
    if (count > 0) {
        throw new BaseException("该位置已绑定该产品，请重新选择");
    }

    // 3. 修改本地数据库
    Device device = getOne(Wrappers.<Device>lambdaQuery()
        .eq(Device::getIotId, dto.getIotId()));
    if (device == null) {
        throw new BaseException("设备不存在");
    }
    BeanUtil.copyProperties(dto, device);
    updateById(device);
}
```

**面试要点**：
- **修改顺序**：先改华为云，再改本地数据库
- **唯一性校验**：修改时需排除当前设备（`.ne(Device::getIotId, dto.getIotId())`）

### 3.8 设备删除

```java
@Override
public void customDeleteDeviceById(String iotId) {
    // 1. 查询设备是否存在
    Device device = getOne(Wrappers.<Device>lambdaQuery()
        .eq(Device::getIotId, iotId));
    if (device == null) {
        throw new BaseException("设备不存在");
    }

    // 2. 先从IoTDA平台删除设备
    DeleteDeviceRequest request = new DeleteDeviceRequest();
    request.withDeviceId(iotId);
    try {
        DeleteDeviceResponse response = iotDAClient.deleteDevice(request);
        if (response.getHttpStatusCode() != 200 &&
            response.getHttpStatusCode() != 204) {
            throw new BaseException("物联网接口 - 删除设备失败");
        }
    } catch (Exception e) {
        throw new BaseException("物联网接口 - 删除设备，同步失败：" + e.getMessage());
    }

    // 3. 再删除本地数据库记录
    boolean removed = removeById(device.getId());
    if (!removed) {
        throw new BaseException("删除本地设备信息失败");
    }
}
```

**面试要点**：
- **删除顺序**：先删华为云，再删本地数据库
- **HTTP状态码**：成功可能是200或204
- **事务问题**：如果本地删除失败，华为云已删除（需补偿机制）

### 4.1 AMQP客户端配置

**文件路径**：`zzyl-nursing-platform/src/main/java/com/zzyl/nursing/job/AmqpClient.java`

```java
@Slf4j
@Component
public class AmqpClient implements ApplicationRunner {

    @Resource
    private HuaWeiIotConfigProperties huaWeiIotConfigProperties;

    @Resource
    private ExecutorService executorService;

    @Override
    public void run(ApplicationArguments args) throws Exception {
        start();
    }

    public void start() throws Exception {
        // 创建多个连接（提高消费能力）
        for (int i = 0; i < huaWeiIotConfigProperties.getConnectionCount(); i++) {
            Connection connection = getConnection();
            ((JmsConnection) connection).addConnectionListener(myJmsConnectionListener);

            Session session = connection.createSession(false, Session.AUTO_ACKNOWLEDGE);
            connection.start();

            MessageConsumer consumer = newConsumer(session, connection,
                huaWeiIotConfigProperties.getQueueName());
            consumer.setMessageListener(messageListener);
        }
    }
}
```

**面试要点**：
- **ApplicationRunner**：Spring Boot启动后自动执行
- **多连接**：提高消息消费能力（配置4个连接）
- **AUTO_ACKNOWLEDGE**：SDK自动确认消息

### 4.2 消息处理

```java
private final MessageListener messageListener = message -> {
    try {
        // 异步处理消息，避免阻塞
        executorService.submit(() -> processMessage(message));
    } catch (Exception e) {
        log.error("submit task occurs exception ", e);
    }
};

private void processMessage(Message message) {
    String contentStr = message.getBody(String.class);
    String topic = message.getStringProperty("topic");
    String messageId = message.getStringProperty("messageId");

    // 解析消息
    JSONObject jsonMsg = JSONUtil.parseObj(contentStr);
    JSONObject jsonNotifyData = jsonMsg.getJSONObject("notify_data");

    if (ObjectUtil.isEmpty(jsonNotifyData)) {
        return;
    }

    // 转换为对象
    IotMsgNotifyData iotMsgNotifyData = JSONUtil.toBean(
        jsonNotifyData, IotMsgNotifyData.class);

    if (ObjectUtil.isEmpty(iotMsgNotifyData.getBody()) ||
        ObjectUtil.isEmpty(iotMsgNotifyData.getBody().getServices())) {
        return;
    }

    // 批量保存设备数据
    deviceDataService.batchInsertDeviceData(iotMsgNotifyData);
}
```

**面试要点**：
- **异步处理**：使用线程池处理消息，避免阻塞AMQP连接
- **消息格式**：华为云IoT平台推送的JSON格式
- **幂等性**：需要考虑消息重复消费的问题

### 6.1 缓存Key设计

```java
public class CacheConstants {
    // IoT产品列表缓存
    public static final String IOT_ALL_PRODUCT_LIST = "iot:all_product_list";
```

### 6.3 设备数据缓存（智能床位功能）

```java
// RoomServiceImpl.java
@Override
public List<RoomVo> getRoomsWithDeviceByFloorId(Long floorId) {
    // 1. 查询基础数据（房间、床位、设备）
    List<RoomVo> roomVos = roomMapper.getRoomsWithDeviceByFloorId(floorId);

    // 2. 从Redis获取设备最新数据
    roomVos.forEach(roomVo -> {
        // 房间设备
        roomVo.getDeviceVos().forEach(deviceInfo -> {
            String jsonStr = (String) redisTemplate.opsForHash()
                .get(CacheConstants.IOT_DEVICE_LAST_DATA, deviceInfo.getIotId());
            if (StringUtils.isEmpty(jsonStr)) {
                return;
            }
            deviceInfo.setDeviceDataVos(JSONUtil.toList(jsonStr, DeviceData.class));
        });

        // 床位设备
        roomVo.getBedVoList().forEach(bedVo -> {
            bedVo.getDeviceVos().forEach(deviceInfo -> {
                String jsonStr = (String) redisTemplate.opsForHash()
                    .get(CacheConstants.IOT_DEVICE_LAST_DATA, deviceInfo.getIotId());
                if (StringUtils.isEmpty(jsonStr)) {
                    return;
                }
                deviceInfo.setDeviceDataVos(JSONUtil.toList(jsonStr, DeviceData.class));
            });
        });
    });

    return roomVos;
}
```

**面试要点**：
- 使用Hash结构存储设备数据，Field为iotId
- 避免每次查询都调用华为云API
- 数据由AMQP接收时实时更新

```java
public class DateTimeZoneConverter {
    public static final ZoneId UTC_ZONE = ZoneOffset.UTC;
    public static final ZoneId SHANGHAI_ZONE = ZoneId.of("Asia/Shanghai");

    /**
     * UTC转上海时区
     */
    public static LocalDateTime utcToShanghai(LocalDateTime utcTime) {
        return utcTime.atZone(UTC_ZONE)
                      .withZoneSameInstant(SHANGHAI_ZONE)
                      .toLocalDateTime();
    }
}
```

## 八、面试常见问题

### Q1：为什么选择华为云IoT平台？

**参考回答**：
1. **国内合规**：数据不出境，符合养老行业数据安全要求
2. **功能完善**：提供设备管理、数据流转、规则引擎等完整功能
3. **AMQP支持**：支持AMQP协议推送设备数据，实时性好
4. **SDK成熟**：提供Java SDK，集成简单
5. **成本可控**：按设备数量和数据量计费，适合中小规模项目

### Q2：产品列表为什么要缓存到Redis？

**参考回答**：
1. **减少API调用**：华为云API有调用频率限制
2. **提高响应速度**：Redis读取比HTTP请求快得多
3. **数据变化频率低**：产品列表不经常变化
4. **降低成本**：减少云服务调用费用

### Q3：设备注册时如何保证数据一致性？

**参考回答**：
```
当前实现：
1. 调用华为云API注册设备
2. 保存到本地数据库

潜在问题：
- 华为云成功，本地失败 → 数据不一致

改进方案：
1. 使用消息队列实现最终一致性
2. 定时任务同步华为云设备列表到本地
3. 本地事务失败时，调用华为云删除接口补偿
```

### Q4：如何处理AMQP消息重复消费？

**参考回答**：
1. **消息ID去重**：使用Redis记录已处理的消息ID
2. **数据库唯一索引**：设备数据表使用唯一索引防止重复插入
3. **幂等性设计**：更新操作使用upsert，插入操作先查询后插入

### Q5：设备绑定位置的设计思路？

**参考回答**：
```
设计思路：
1. 区分随身设备和固定设备
2. 随身设备绑定老人，固定设备绑定物理位置
3. 物理位置支持三级：楼层→房间→床位

数据结构：
- locationType: 0=随身设备, 1=固定设备
- physicalLocationType: 0=楼层, 1=房间, 2=床位, -1=老人
- bindingLocation: 绑定对象的ID

业务规则：
- 同一位置不能绑定相同类型的设备
- 一个设备只能绑定一个位置
```

### Q6：AMQP连接断开如何处理？

**参考回答**：

### Q7：如何优化设备列表查询性能？

**参考回答**：
1. **数据库索引**：在`iot_id`、`product_key`、`binding_location`上建索引
2. **分页查询**：使用PageHelper实现分页
3. **缓存设备状态**：设备状态缓存到Redis，减少华为云API调用
4. **异步查询**：设备详情和设备数据可以异步并行查询
