# 设备管理功能 - 面试提问问题清单

## 一、业务理解类

### Q1: 请介绍一下设备管理功能在整个养老系统中的作用？
**考察点**：业务理解、系统架构认知
**参考答案要点**：
- 对接华为云IoT平台，实现物联网设备统一管理
- 为智能监测、健康预警等业务提供基础支撑
- 包括产品同步、设备注册、设备绑定、数据接收等核心功能

### Q2: 设备绑定位置的设计思路是什么？随身设备和固定设备有什么区别？
**考察点**：业务设计能力、数据建模
**参考答案要点**：
- 随身设备绑定老人，固定设备绑定物理位置
- 物理位置支持三级：楼层→房间→床位
- locationType区分类型，physicalLocationType区分物理位置层级
- 同一位置不能绑定相同类型的设备

## 二、技术实现类

### Q3: 产品列表为什么要缓存到Redis？缓存策略是怎样的？
**考察点**：缓存设计、性能优化意识
**参考答案要点**：
- 减少华为云API调用频率（有调用限制）
- 提高响应速度（Redis比HTTP请求快）
- 产品列表变化频率低，适合缓存
- 使用String类型存储JSON，手动触发同步

### Q4: 设备注册时做了哪些校验？为什么需要这些校验？
**考察点**：业务逻辑完整性、数据一致性
**参考答案要点**：
- 设备名称唯一性校验
- 设备标识(nodeId)唯一性校验
- 位置+产品组合唯一性校验（同一位置不能绑定同类型设备）
- 防止数据重复、业务冲突

### Q5: 设备注册时如何保证华为云和本地数据库的数据一致性？
**考察点**：分布式事务、系统设计
**参考答案要点**：
- 当前实现：先调用华为云API，再保存本地数据库
- 潜在问题：华为云成功但本地失败导致不一致
- 改进方案：消息队列实现最终一致性、定时同步任务、补偿机制

### Q6: AMQP消息是如何接收和处理的？为什么要使用线程池？
**考察点**：消息队列、异步处理
**参考答案要点**：
- 实现ApplicationRunner接口，Spring Boot启动后自动连接
- 配置多个连接（4个）提高消费能力
- 使用线程池异步处理消息，避免阻塞AMQP连接
- Session.AUTO_ACKNOWLEDGE自动确认模式

## 三、深度追问类

### Q7: 如何处理AMQP消息重复消费问题？
**考察点**：消息可靠性、幂等性设计
**参考答案要点**：
- 消息ID去重：使用Redis记录已处理的消息ID
- 数据库唯一索引：防止重复插入
- 幂等性设计：更新操作使用upsert

### Q8: 设备修改和删除时，操作顺序是怎样的？为什么？
**考察点**：系统设计、异常处理
**参考答案要点**：
- 顺序：先操作华为云，再操作本地数据库
- 原因：华为云是数据源头，保证云端数据正确
- 问题：本地操作失败时华为云已变更，需补偿机制

### Q9: 华为云返回的时间为什么要做时区转换？如何实现的？
**考察点**：细节处理、Java时间API
**参考答案要点**：
- 华为云返回UTC时间，需转换为本地时间（上海时区）
- 使用Java 8的ZoneId和ZonedDateTime
- 封装DateTimeZoneConverter工具类统一处理

### Q10: AMQP连接断开如何处理？配置了哪些重连参数？
**考察点**：系统可靠性、运维意识
**参考答案要点**：
- 配置自动重连：reconnectDelay、maxReconnectDelay、maxReconnectAttempts
- 实现JmsConnectionListener监听连接状态
- 记录日志便于排查问题

## 四、扩展思考类

### Q11: 如果让你优化设备列表查询性能，你会怎么做？
**考察点**：性能优化、数据库优化
**参考答案要点**：
- 数据库索引优化（iot_id、product_key、binding_location）
- 分页查询
- 设备状态缓存到Redis
- 异步并行查询设备详情和设备数据

### Q12: 如何实现设备离线告警功能？
**考察点**：系统设计、业务扩展
**参考答案要点**：
- 定时任务同步华为云设备状态
- 状态变化时触发告警
- 结合消息推送通知相关人员
- 记录告警日志便于追溯

## 五、代码细节类

### Q13: 设备密钥是如何生成的？为什么用UUID？
**考察点**：安全意识、代码细节
**参考答案要点**：
- 使用UUID生成随机密钥
- 去除横线保证格式统一
- UUID随机性强，难以猜测

### Q14: 查询设备详情时，数据来源有哪些？为什么要这样设计？
**考察点**：系统设计、数据整合
**参考答案要点**：
- 本地数据库：设备基本信息、绑定位置
- 华为云API：设备状态、激活时间等实时数据
- 原因：基本信息变化少，状态需要实时获取

### Q15: Redis缓存设备最新数据的Key结构是怎样的？为什么用Hash？
**考察点**：Redis数据结构、缓存设计
**参考答案要点**：
- Key: iot:device_last_data
- Field: iotId
- Value: 设备数据JSON
- Hash优势：一个Key管理所有设备，通过Field快速定位
